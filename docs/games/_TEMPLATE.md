## Summary

One paragraph: what the player does, what the dealer does, how a round ends.

## Rules

1. Betting: which bets exist, which are optional, table limits.
2. The round, step by step: every roll, deal and decision, in order.
3. Settlement: when each bet wins, pushes or loses.
4. Edge cases: ties, reshuffles, maximum payouts.

## Mathematics

- Card source used for the declared figures (infinite shoe) and the effect of
  a finite shoe, if material.
- Optimal or reference strategy for decisions, when the game has any.
- Exact test: what is enumerated and how many outcomes it covers.
- Monte Carlo test: seed, rounds and the tolerance (±0.15 pp), with the
  standard error that justifies the round count.

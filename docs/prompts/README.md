# Prompt history

This repository is built with an AI coding agent. Each file in this folder holds one prompt given
to it, verbatim, in order. Together they record the brief behind every part of the code; the
commit history shows what each prompt produced. Prettier skips this folder so the text stays
exactly as written.

The games were developed under Portuguese working titles and renamed to English by prompt 006.
The prompts quote them as they were written, so the earlier ones use the working titles; the
headings and this index use the English names.
